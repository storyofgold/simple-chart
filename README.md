# Market Analysis AI Dashboard

A dashboard that provides AI-powered daily financial market analysis, featuring real-time charts from TradingView and summaries generated by the Gemini API.

## Running Locally

1.  **Install Dependencies**
    ```bash
    npm install
    ```

2.  **Set Up Environment Variables**
    - Create a new file named `.env` in the root of the project.
    - Add your Gemini API key to the file like this:
      ```
      VITE_API_KEY=YOUR_GEMINI_API_KEY_HERE
      ```

3.  **Run the Development Server**
    ```bash
    npm run dev
    ```
    The application will be available at `http://localhost:5173`.

## Deployment to GitHub Pages

This project is configured for automated deployment to GitHub Pages using GitHub Actions.

### One-Time Setup

You only need to do this once for your repository.

1.  **Update Vite Config**
    - Open `vite.config.ts`.
    - Change the `base` property from `'/<YOUR_REPOSITORY_NAME>/'` to match your repository's name.
    - For example, if your repository URL is `https://github.com/john-doe/market-analysis-app`, the `base` should be `'/market-analysis-app/'`.

2.  **Add API Key to GitHub Secrets**
    - In your GitHub repository, go to **Settings** > **Secrets and variables** > **Actions**.
    - Click **New repository secret**.
    - For the **Name**, enter `VITE_API_KEY`.
    - For the **Secret**, paste your Gemini API key.
    - Click **Add secret**.

3.  **Enable GitHub Pages**
    - Push your updated code to the `main` branch. The GitHub Action will run automatically and create a new branch called `gh-pages`.
    - In your GitHub repository, go to **Settings** > **Pages**.
    - Under "Build and deployment", set the **Source** to **Deploy from a branch**.
    - Select the **`gh-pages`** branch and the `/ (root)` folder.
    - Click **Save**.

Your website will be deployed to the URL shown on that page. From now on, every time you `git push` to the `main` branch, the website will update automatically!
